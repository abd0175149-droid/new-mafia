# 34 — رسم المظهر المشترى على بطاقة اللاعب

> **الإصدار:** 1.0 · **كُتب:** 1 أغسطس 2026 · **المصدر:** `chips-design.contract.ts` المنشور + مكوّنات الرسم في الواجهة.

---

## 1. الهدف والنطاق

**داخل النطاق:** ترجمة عقد التصميم إلى Dart، ورسم ما يُلبَس على بطاقة اللاعب: **الإطار** (عشر قنوات تأثير) · **الشعار** (ثمانية رسوم متجهيّة) · **اللقب** (لوحة قابلة للتخصيص) · **تأثير الاسم**. ثم مزوّد المظهر وقنوات تحديثه الثلاث، ومواضع الظهور: بطاقة اللاعب في اللعب، وقسم «بطاقتي بمظهري» في الملف الشخصي، ومرآة الخزنة، ومصغّرات الكتالوج.

**خارج النطاق:**

> 🔴 **التشريفة والإقصاء والاحتفال بعيد الميلاد لا تُبنى في التطبيق إطلاقاً.**
> فحص مواضع الاستعمال في الكود: `EntranceOverlay` و`EliminationFx` و`BirthdayCelebration` تُستورَد في `app/display/*` **فقط** — أي شاشة القاعة، وهي خارج نطاق التطبيق بنصّ [00-MASTER-PLAN §2.1](00-MASTER-PLAN.md). اللاعب يشتريها من هاتفه ويراها على التلفاز.
> **الاستثناء الوحيد:** معاينتها داخل الخزنة — ومواصفتها في [33 §4.2د](33-chips-store.md)، وهي محاكاة مبسّطة لا نقلٌ للتأثير الأصليّ.

## 4. الواجهة والتجربة تفصيلياً

### 4.0 لماذا وُجد هذا الملف

كل ما يشتريه اللاعب كان يظهر على شاشة القاعة فقط. بطاقته في يده طوال السهرة تُرسم بلا إطار ولا لقب ولا تأثير اسم — والخادم يبثّ `chips:cosmetics-updated` على غرفة اللاعب منذ البداية **ولا مستمع له في الواجهة كلّها**. فقيمة كل شراء تنهار إلى «فقط حين أكون في النادي وأنظر إلى التلفاز في اللحظة الصحيحة».

**في التطبيق يجب أن يكون المظهر حاضراً في يد صاحبه.**

### 4.1 مصدر المظهر ومواضع الظهور

| الموضع | المصدر |
|---|---|
| بطاقة اللاعب أثناء اللعب | مزوّد المظهر (§6.1) |
| «بطاقتي بمظهري» في الملف الشخصي | نفسه |
| مرآة الخزنة | مظهر مدموج بالعنصر المُعايَن ([33](33-chips-store.md)) |
| مصغّر عنصر في الكتالوج | `config` العنصر وحده — **لا مظهر اللاعب** |

في الملف الشخصي يظهر القسم **فقط** إن وُجد `frame` أو `title` أو `nameFx`.

> ⚠️ **رتّبت هذه القاعدة عطلاً في الويب:** صفحة الملف تعود مبكراً عند التحميل والخطأ، فوضع الخطّاف بعدهما غيّر عدد الخطّافات بين الرسمتين وأسقط React. في Flutter لا وجود لهذا القيد، لكن **اقرأ المظهر عبر مزوّد لا داخل بناء مشروط** حفاظاً على البنية نفسها.

### 4.2 الإطار — عشر قنوات

كل قناة مستقلّة ولها `enabled`. القيم الافتراضية **مُلزِمة** (منقولة من `FX_DEFAULTS`):

| القناة | الحقول والافتراضيّ |
|---|---|
| `border` | `color #f59e0b` · `width 2` · `inset 0` · `style solid\|gradient\|traveling` · `gradientColors ['#f59e0b','#f59e0b']` · `travelSpeed 3` |
| `glow` | `color #f59e0b` · `size 12` · `opacity 0.4` · `pulseEnabled false` · `pulseDuration 2.5` |
| `shimmer` | `color #ffffff` · `opacity 0.1` · `duration 4` |
| `particles` | `count 4` · `color #f59e0b` · `size 3` · `orbitRadius '90px'` · `baseDuration 5` · `originX 50` · `originY 50` · `animationType orbit\|burst` |
| `corners` | `color #f59e0b` · `size 12` · `width 2` · `pulseEnabled false` |
| `frame` | `type none\|simple\|greek\|islamic\|deco\|royal` · `color #f59e0b` · `opacity 0.7` · `strokeWidth 1.5` · `animate true` |
| `gradientOverlay` | `color #f59e0b` · `opacity 0.1` · `direction 'to top'` |
| `floating` | `content ''` · `position top` · `size 18` · `animation float\|bounce\|spin` · `glowColor #f59e0b` |
| `badge` | `emoji ''` · `label ''` · `bgColor rgba(0,0,0,0.6)` · `textColor #fcd34d` · `borderColor rgba(245,158,11,0.4)` |
| `nameEffect` | `color #ffffff` · `glowColor #f59e0b` · `glowSize 8` |

#### 🔴 قاعدة الدمج — المدفوع يضيف ولا يمحو

```
لكل قناة:  الناتج = (المدفوعة.enabled) ? المدفوعة : قناة الرتبة
```

الدمج **على مستوى القناة لا الكائن**. أي أن إطاراً مدفوعاً يفعّل `glow` وحده يأخذ توهّجه ويُبقي بقيّة قنوات الرتبة كما هي.

> استبدال الكائن كاملاً يمحو تأثيرات الرتبة التي كسبها اللاعب بلعبه — وهو ما وقع مرّة وأُصلح.

#### التطبيع لا يرمي أبداً

`normalizeFx(any)` يعيد كائناً كاملاً مهما كان المُدخل: لون غير مطابق لـ`^#[0-9a-fA-F]{6}$` → الافتراضيّ؛ رقم خارج المدى → مقصوص؛ قيمة خارج القائمة المغلقة → الافتراضيّ؛ `null`/مصفوفة/نصّ → الافتراضيّ كاملاً. **هذه القاعدة تسري على كل مطبِّعات هذا الملف.**

### 4.3 الشعار — ثمانية رسوم متجهيّة

`don` (تاج) · `blood` (خنجر) · `neon` (لافتة) · `bullet` (رصاصات نحاسية) · `smoke` (قبّعة نوار) · `deal` (رقاقة كازينو) · `crime` (طبشور جريمة) · `champ` (إكليل البطل).

- **رسم متجهيّ لا صور** — يُنفَّذ بـ`CustomPainter` أو `flutter_svg` بمسارات مضمّنة (لا ملفّات خارجية).
- المقاس على البطاقة: `sm → 40` · `md → 56` · `lg → 72`.
- **يطفو فوق الحافّة العليا للبطاقة** — ولهذا كل حاوية تقصّ البطاقة تحتاج متنفَّساً علوياً (`HEADROOM = 17` عند `md`؛ يُقاس نسبةً في غيره). القصّ بلا متنفَّس يبتر التاج.
- `champ` **يُمنح ولا يُشترى** — إكليل بطل الموسم، يُسنَد تلقائياً لصاحب المركز الأوّل.

### 4.4 اللقب

**أربعة أنماط:** `gold` · `blood` · `ghost` · `custom`.

الثلاثة الأولى مسارات ثابتة (نمط جاهز)، و**`custom` وحده يُبنى من البيانات** عبر `TitlePlaque`:

```dart
class TitlePlaque {
  Bg bg;          // type: solid|gradient · color · color2 · angle · blur
  TextSpec text;  // color · size · weight · letterSpacing
  BorderSpec border; // enabled · color · width · style(solid|dashed|dotted|double) · radius
  GlowSpec glow;  // enabled · color · size
  ShadowSpec shadow; // enabled · color · size
  AnimSpec anim;  // type(none|pulse|breathe|shimmer|float) · duration · intensity
  Layout layout;  // paddingX · paddingY · marginTop · maxWidth
}
```

**الافتراضيّ (`gold`):** خلفية `rgba(69,26,3,0.8)` صلبة بضبابية 4 · نصّ `#fcd34d` بمقاس 10 ووزن 900 · حدّ `rgba(245,158,11,0.6)` بعرض 1 ونصف قطر 7 · توهّج `rgba(245,158,11,0.5)` بمقاس 8 · بلا ظلّ · بلا حركة · حشوة `8×1`، هامش علويّ 3، أقصى عرض 92.

`blood`: خلفية `rgba(69,10,10,0.8)`، نصّ `#fca5a5`، حدّ `rgba(220,38,38,0.6)`، بلا توهّج، حركة `pulse 1.6s` بشدّة 0.75.
`ghost`: خلفية `rgba(24,24,27,0.7)`، نصّ `#d4d4d8`، حدّ `rgba(161,161,170,0.5)`، بلا توهّج، حركة `breathe 3s` بشدّة 0.58.

`maxWidth` نسبة مئوية من عرض البطاقة. النصّ سطر واحد بقصّ.

### 4.5 تأثير الاسم

```dart
class NameFx {
  bool enabled;                    // false
  String color;        // #ffffff
  String glowColor;    // #f59e0b
  double glowSize;     // 8
  String style;        // glow | gradient | outline | engraved
  String color2;       // #f59e0b   (للتدرّج)
  double angle;        // 90
  String outlineColor; // #000000
  double outlineWidth; // 1
  String anim;         // none | pulse | flicker | sweep | cycle
  double animDuration; // 2.5
  String enter;        // none | fade | rise
}
```

| النمط | الرسم في Flutter |
|---|---|
| `glow` | `TextStyle.shadows` — ظلّ بلا إزاحة بنصف قطر `glowSize` ولون `glowColor` |
| `gradient` | `ShaderMask` بتدرّج خطّيّ من `color` إلى `color2` بزاوية `angle` |
| `outline` | طبقتا نصّ: السفلى `PaintingStyle.stroke` بعرض `outlineWidth` ولون `outlineColor`، والعليا مملوءة |
| `engraved` | ظلّان متقابلان: فاتح أعلى-يمين ومعتم أسفل-يسار |

| الحركة | التنفيذ |
|---|---|
| `pulse` | `opacity` أو `glowSize` ذهاباً وإياباً على `animDuration` |
| `flicker` | تذبذب غير منتظم في الشفافية |
| `sweep` | بريق يعبر النصّ (`ShaderMask` متحرّك) |
| `cycle` | تدوير الصبغة بين `color` و`color2` |

`enter` يُطبَّق **مرّة واحدة عند أوّل ظهور**: `fade` (شفافية) أو `rise` (انزلاق من الأسفل).

**مصدر التأثير على البطاقة:** `cosmetics.nameFx.config.nameEffect` إن وُجد، وإلا قناة `nameEffect` من الإطار المدموج.

### 4.6 المصغّر في الكتالوج

يرسم العنصر بمقاس صغير حسب نوعه: **إطار** → مستطيل بنسبة البطاقة بتأثيراته · **لقب** → اللوحة وحدها · **تأثير اسم** → الاسم مطبَّقاً عليه · **تشريفة/إقصاء** → أيقونة تمثيلية ساكنة (المعاينة الحيّة في المرآة) · **نغمة** → أيقونة صوت.

المقاسات المستعملة: **54** (الشبكة) · **44** (الصفوف) · **32** (الخزنة المقفلة).

## 5. التكيّف مع الشاشات 6→11 إنش

المظهر **يتبع البطاقة** ولا يُقاس مستقلاً: كل قيمة بالبكسل في العقد نسبةٌ من مقاس البطاقة الأساس (`md = 224×320`). عند تكبير البطاقة تُضرب القيم بنفس المعامل.

| | compact | medium | expanded |
|---|---|---|---|
| البطاقة في الملف الشخصي | `md` | `md` | `lg` |
| مقاس الشعار | 56 | 56 | 72 |
| الجسيمات | كما هي | كما هي | **قلّلها إلى النصف** إن تجاوز عدد البطاقات المرئية 6 (§13) |

**لا تُعِد حساب أنصاف الأقطار والحشوات يدوياً لكل فئة** — اضرب في معامل واحد، وإلا انفصل المظهر عن البطاقة.

## 6. المنطق والتدفّقات

### 6.1 مزوّد المظهر — ثلاث قنوات تحديث

**كي لا يعتمد الظهور على قناة واحدة قد تنقطع:**

1. **جلب أوّليّ** عند التركيب — `GET /api/chips/store/cosmetics`
2. **بثّ لحظي** — `chips:cosmetics-updated` على غرفة `player:{id}`
3. **إعادة جلب عند العودة للواجهة** — الهاتف ينام كثيراً

#### 🔴 مصيدة الغرفة — أهمّ فقرة في هذا الملف

البثّ يصل على غرفة `player:{id}`، والانضمام إليها يقع **مرّة واحدة عند الاتصال** من رمز المصافحة. فإن اتّصل السوكِت **قبل** أن يُكتب الرمز — وهو ترتيب شائع لأن السوكِت وحدة مفردة تُنشأ عند أوّل استيراد — فاللاعب **ليس في الغرفة ولن يدخلها أبداً**، وتوسيع قراءة الرمز في الجلب لا يفيده إطلاقاً.

**العلاج:** تحقّق من وجود رمز المصافحة، وإن غاب **أعد المصافحة برمزٍ حاضر** (`reconnectSocketAuth`). في Flutter: تأكّد أن `SocketService` لا يتّصل قبل أن تُقرأ الجلسة من `SessionStore`، وبعد كل تسجيل دخول أعد المصافحة صراحةً. ([04](04-socket-layer.md) و[05](05-session-auth.md)).

### 6.2 دورة الحياة

```
onInit  → قراءة الرمز؛ إن غاب فلا شيء
        → جلب أوّليّ
        → فحص رمز المصافحة؛ إعادة المصافحة إن غاب
        → الاشتراك في chips:cosmetics-updated
onResume → إعادة جلب
onDispose → إلغاء الاشتراك
```

### 6.3 قاعدة الفشل

**المظهر زخرفة.** فشل جلبه **لا يعطّل شاشة ولا يرمي ولا يعرض خطأً**. البطاقة تُرسم بمظهر الرتبة وحده، وهذا سلوك صحيح لا حالة عطل.

### 6.4 حالات حدّية

| الحالة | السلوك |
|---|---|
| `cosmetics` = null | البطاقة بمظهر الرتبة وحده |
| `config` فاسد أو ناقص | التطبيع يعيد الافتراضيّ — لا انهيار ولا خانة فارغة |
| نوع تصميم مجهول (أضافته اللوحة قبل التطبيق) | تُرسم القنوات المفهومة ويُتجاهل المجهول بصمت — **ولا تُسقط البطاقة** |
| انتهاء الإيجار أثناء الجلسة | الخادم يبثّ مظهراً محدَّثاً؛ العنصر يختفي بلا تدخّل من العميل |
| اسم اللاعب فارغ | «أنت» |

## 7. عقود التكامل

### REST

| الطريقة | المسار | الاستجابة |
|---|---|---|
| GET | `/api/chips/store/cosmetics` | `{ success, cosmetics, rankTier }` |
| GET | `/api/chips/store/cosmetics/:playerId` | نفسها للاعب آخر (تُستعمل من شاشة القاعة — **لا يحتاجها التطبيق**) |

```json
{
  "success": true,
  "rankTier": "CAPO",
  "cosmetics": {
    "frame":   { "itemId": 14, "config": { }, "emblemId": "don" },
    "title":   { "itemId": 21, "config": { "text": "…", "style": "custom", "plaque": { } } },
    "nameFx":  { "itemId": 33, "config": { "nameEffect": { } } },
    "entrance":   { },
    "elimination":{ }
  }
}
```

- كل خانة قد تكون `null`.
- `itemId` يُستعمل لمعرفة **أيّ عنصر مُجهَّز** (شارة «مُجهَّز» في الكتالوج).
- `entrance` و`elimination` تصلان في الحمولة و**يتجاهلهما التطبيق** — مواضعهما شاشة القاعة.

### Socket

| الحدث | الحمولة | الغرفة |
|---|---|---|
| `chips:cosmetics-updated` | `{ cosmetics }` | `player:{id}` |
| `player:cosmetics-updated` | نفسها | شاشة القاعة — **لا يستمع لها التطبيق** |

## 8. نماذج Dart المطلوبة

```dart
@freezed
class PlayerCosmetics with _$PlayerCosmetics {
  const factory PlayerCosmetics({
    CosmeticSlot? frame,
    CosmeticSlot? title,
    CosmeticSlot? nameFx,
  }) = _PlayerCosmetics;
  factory PlayerCosmetics.fromJson(Map<String, dynamic> j) => _$PlayerCosmeticsFromJson(j);
}

@freezed
class CosmeticSlot with _$CosmeticSlot {
  const factory CosmeticSlot({
    int? itemId,
    @Default(<String, dynamic>{}) Map<String, dynamic> config,
    String? emblemId,
  }) = _CosmeticSlot;
}
```

ثم نماذج مطبَّعة تُشتقّ من `config`: `FxChannels` (عشر قنوات) · `TitlePlaqueSpec` · `NameFxSpec`.

**دوال التطبيع تُنقَل حرفياً من العقد** — نفس المدايات ونفس الافتراضيات ونفس القوائم المغلقة:
`normalizeFx` · `mergeFx` · `normalizeTitlePlaque` · `normalizeNameFx` · `normalizeEmblemId`.

> 🔴 **العقد هو `chips-design.contract.ts` وحده.** أي اختلاف في قيمة افتراضية أو حدّ قصٍّ يعني أن اللاعب يرى على هاتفه غير ما يراه على شاشة القاعة — وقد دفع ثمن ما رآه في المتجر. عند أي تعديل في العقد **يُعدَّل هذا الملف معه**، ويُفضَّل توليد ثوابت Dart من العقد آلياً بدل نسخها يدوياً.

## 9. الحزم المستخدمة

`freezed`/`json_serializable` · `flutter_animate` (النبض والتنفّس والوميض) · `CustomPainter` (الشعارات والإطارات والزوايا والجسيمات) · `flutter_riverpod`.

**لا `flutter_svg` إن أمكن** — الشعارات الثمانية مسارات معروفة، ورسمها بـ`CustomPainter` أخفّ ويتجنّب تحليل XML لكل بطاقة في شبكة.

## 10. اختلافات Android / iOS

| المجال | Android | iOS |
|---|---|---|
| الظلال والتوهّج | `BoxShadow`/`Shadow` مباشرة | نفسها — لكن التوهّج الكبير أثقل على أجهزة أقدم؛ اقصص `glowSize` عند 24 |
| `backdrop blur` (خلفية اللقب) | `BackdropFilter` — **مكلف**؛ استعمله على اللقب وحده لا على البطاقة | أرخص نسبياً، وتبقى القاعدة |
| الجسيمات المتحرّكة | `Ticker` واحد مشترك لكل البطاقات المرئية | نفسه — **لا مؤقّت لكل جسيم** |
| تكبير خطّ النظام | يؤثّر على نصّ اللقب والاسم — قيّده بـ`clamp(1.0, 1.3)` وإلا تجاوز اللقب البطاقة | نفسه (Dynamic Type) |
| تقليل الحركة | `MediaQuery.disableAnimations` | نفسه — **احترمه**: أوقف `pulse`/`flicker`/`sweep` وأبقِ المظهر الساكن |

## 12. معايير القبول

- [ ] القنوات العشر كلّها مرسومة، وكلٌّ تحترم `enabled`.
- [ ] 🔴 الدمج **على مستوى القناة**: إطار مدفوع يفعّل `glow` وحده لا يمحو بقيّة تأثيرات الرتبة.
- [ ] الافتراضيات تطابق `FX_DEFAULTS` حرفياً — قيمةً قيمة.
- [ ] التطبيع لا يرمي أبداً: `null`، مصفوفة، نصّ، لون فاسد، رقم خارج المدى، قيمة خارج القائمة.
- [ ] الشعارات الثمانية مرسومة متجهيّاً، وبمقاسات 40/56/72.
- [ ] الشعار يطفو فوق الحافّة، وكل حاوية قاصّة تترك متنفَّساً علوياً.
- [ ] أنماط اللقب الأربعة، و`custom` مبنيّ من البيانات بكل حقوله.
- [ ] حركات اللقب الخمس، وحركات الاسم الخمس، ومداخل الاسم الثلاثة.
- [ ] أنماط الاسم الأربعة مرسومة صحيحاً (خصوصاً `gradient` بـ`ShaderMask` و`outline` بطبقتين).
- [ ] المظهر يظهر على: بطاقة اللعب · الملف الشخصي · مرآة الخزنة.
- [ ] قسم الملف الشخصي يظهر فقط عند وجود إطار أو لقب أو تأثير اسم.
- [ ] 🔴 **البثّ يصل فعلاً**: تجهيز عنصر من الخزنة يغيّر البطاقة **بلا إعادة تحميل** — وهذا يقتضي التحقّق من الغرفة (§6.1).
- [ ] القنوات الثلاث كلّها تعمل: الجلب الأوّليّ، والبثّ، والعودة من الخلفية.
- [ ] فشل الجلب يُبقي البطاقة بمظهر الرتبة **بلا خطأ ظاهر**.
- [ ] نوع تصميم مجهول لا يُسقط البطاقة.
- [ ] لا يُبنى تأثير تشريفة ولا إقصاء ولا احتفال ميلاد خارج معاينة الخزنة.
- [ ] احترام «تقليل الحركة».
- [ ] البطاقة بمظهر كامل تحافظ على 60fps في شبكة من ستّ بطاقات (§13).

## 13. ملاحظات أداء وأمان

**الأداء هو الخطر الحقيقيّ في هذا الملف.** بطاقة واحدة قد تحمل توهّجاً نابضاً وبريقاً عابراً وأربع جسيمات مدارية وحدّاً متحرّكاً وشعاراً طافياً — وشبكة الكتالوج تعرض ستّاً.

1. **`RepaintBoundary` حول كل بطاقة ومصغّر.** بدونه تُعاد رسم الشبكة كلّها عند أي إطار متحرّك.
2. **مؤقّت واحد مشترك** يقود كل الحركات المرئية — لا `AnimationController` لكل قناة لكل بطاقة.
3. **الحركة تتوقّف خارج الشاشة.** استعمل `VisibilityDetector` أو أوقف المؤقّت عند `AppLifecycleState.paused`.
4. **قلّل الجسيمات في الشبكات:** أكثر من 6 بطاقات مرئية ⇒ النصف. المرآة والملف الشخصي بطاقة واحدة، فلا تقليل فيهما.
5. **`BackdropFilter` على اللقب وحده** — لا على البطاقة.
6. **القيم المطبَّعة تُخزَّن مؤقّتاً** (`memoize` على `config`) — لا تُطبَّع في كل `build`.

**أمان:**
- المظهر المعروض **مصدره الخادم دائماً**. لا تسمح بمظهر يأتي من ردّ عملية شراء بلا تأكيد الخادم — كل شراء ناجح يُتبَع بإعادة جلب المظهر.
- المظهر **زخرفة لا حالة لعب**: لا يُشتقّ منه دور ولا فريق ولا صلاحية، ولا يُبثّ عنه شيء إلى لاعبين آخرين من جهاز اللاعب.
- `config` نصّ حرّ من قاعدة البيانات — **لا تُنفّذ منه شيئاً** ولا تبنِ منه مسارات ملفّات؛ يُقرأ كبيانات رسم فقط، وضمن القوائم المغلقة أعلاه.
